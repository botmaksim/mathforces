# Mathforces

Система для проведения математических контестов (серверная и клиентская часть на C++ Qt).

> **Внимание:** В предыдущих версиях проект использовал тяжелый фреймворк `userver` (Яндекс), из-за чего скачивались огромные библиотеки (Boost, OpenSSL, gRPC и т.д.), появлялись варнинги и сборка весила много гигабайт. **В этой версии мы полностью перешли на легковесный Qt (QHttpServer/QTcpServer)**. Пожалуйста, соберите проект с чистого листа, чтобы избавиться от старых кешей и тяжелых файлов!

## Быстрая установка одной командой (Debian/Ubuntu)

Перейдите в пустую папку (или удалите все старые файлы сборки) и выполните единый bash-скрипт. 
Убедитесь, что у вас есть права sudo (скрипт установит пакеты и настроит PostgreSQL):

```bash
chmod +x setup.sh && ./setup.sh
```

**Что автоматически сделает этот скрипт:**
1. Установит все нужные легковесные пакеты (`qt6`, `postgresql`, `typst` и т.д.).
2. Автоматически запустит службу БД и создаст локальную базу `mathforces_db` с нужными таблицами.
3. Полностью удалит старую папку `build` с остатками кэша от `userver` (если она была).
4. Соберёт сервер и клиент в `Ультра-быстром Release` профиле.

## Запуск 

После того как скрипт успешно завершит работу:

1. Отредактируйте сгенерированный файл `config.env`, добавив ваш `OPENROUTER_API_KEY`.
2. Запустите сервер (в первом терминале):
   ```bash
   cd build
   ./server/Server
   ```
3. Запустите клиент (во втором терминале):
   ```bash
   cd build
   ./client/Client
   ```

### Исправление ошибки OAuth (Google)
Если при входе через Google возникает ошибка `Invalid Origin` или `redirect_uri_mismatch`:
1. В Google Cloud Console (API и сервисы -> Учетные данные), где ваш клиент OAuth.
2. **Разрешенные источники JavaScript**: `http://127.0.0.1:8080` (без путей на конце!)
3. **Разрешенные URI перенаправления**: `http://127.0.0.1:8080/api/oauth_callback_client` (точный путь обязателен).
4. Сохраните и подождите ~5 минут для вступления изменений в силу.
